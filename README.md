# Steve's AI

A modern AI-powered landing page built with React, TypeScript, Vite, and Tailwind CSS.

## Live Demo

https://steves-ai.pages.dev/

## Features

- Responsive Design
- Hero Section
- About
- Services
- Portfolio
- Blog
- Contact Form
- AI Chat Widget
- Fast Performance

## Tech Stack

- React
- TypeScript
- Vite
- Tailwind CSS

## Installation

```bash
git clone https://github.com/your-username/steves-ai.git
cd steves-ai
npm install
npm run dev
```
